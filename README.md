# Fares Glam · Web para GitHub Pages

1. Sube todo el contenido de esta carpeta al repositorio de GitHub.
2. En GitHub entra a **Settings > Pages**.
3. En **Deploy from a branch**, selecciona la rama `main` y la carpeta `/ (root)`.
4. Guarda y espera la URL de GitHub Pages.

La web ya queda conectada al Apps Script entregado. Para recibir pedidos y administrar inventario, publica esta carpeta en GitHub Pages.

```js
export const API_URL = 'URL_DE_TU_APPS_SCRIPT_TERMINADA_EN_/exec';
```

Desde Admin podrás pulsar **Pasar las fotos a Drive**. Esa migración sube las 49 imágenes iniciales y guarda el vínculo de cada una en el Sheet. Luego podrás reemplazarlas, editar stock, precio, nombre, visibilidad y estado de agotado.
